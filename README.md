# Food Order Management — Backend

Node.js + Express + MongoDB (Mongoose) REST API for the Food Order Management System.


## Features

- JWT authentication (admin/staff roles)
- Menu item CRUD
- Order creation with live status workflow (Pending → Preparing → Ready → Completed / Cancelled)
- Payment status tracking
- Dashboard aggregation endpoints for charts (revenue trend, orders by status, top-selling items, order type split)
